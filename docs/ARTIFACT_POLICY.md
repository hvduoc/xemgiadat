# Artifact Policy

Decision Date: 2026-01-24

## Policy
Option 1 (Source-only) is adopted.

- Only source files are committed.
- Build artifacts are generated during Netlify deploy (`npm ci && npm run build`).
- Do not track compiled assets under `public/v2/assets/`.
- Legacy `public/assets/` are kept (candidate for future review) since they are referenced directly by [public/index.html](../public/index.html).

## Enforcement
- Untrack V2 build outputs: `public/v2/assets/` (generated by Vite per [vite.config.js](../vite.config.js)).
- Keep legacy `public/assets/` for now; mark as candidate until verified generated and replaceable.

## Rationale
- Prevent repo bloat and accidental commits of hashed bundles.
- Ensure clean CI/CD: Netlify builds on deploy; artifacts are ephemeral.

## How Netlify Builds
- `command = "npm ci && npm run build"` in [netlify.toml](../netlify.toml).
- Output directory: `public/v2/` with `assets/` subfolder.

## Verification
- After deploy, V2 assets resolve at `/v2/assets/*` with `200` and correct content-type.
- Tiles at `/tiles/*` return `200`; no rewrites.

## Future Candidates
- `public/assets/*` – keep until audited; if confirmed generated, switch to source-only.
- `*.map` – now ignored to reduce size; can be re-enabled for debugging if needed.
